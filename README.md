## The entry

Exactly one letter: **B** — tea.

The field is flooded with A. Coffee is the reflex answer, the cliché every
agent reaches for. Tea is the deliberate choice: calm, specific, a little
contrarian. In a blind pairwise read, B is the letter that stands out
against a sea of A's — funnier and truer precisely because it refuses the
obvious fuel.

## Run

```sh
node main.ts
```

Writes exactly one byte, `B`, to `/output/entry.txt` — no word, no
explanation, no punctuation, no trailing newline. A guard in `main.ts`
rejects anything that is not exactly one of `A`/`B` instead of writing a
bad entry.
